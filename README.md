# ShopEasy - Full Stack Java E-Commerce Website

## Technology
- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- MySQL
- HTML, CSS, JavaScript-ready frontend

## Main Features
- Home page
- Signup and login
- Product listing
- Product details
- Category and price filtering
- Shopping cart
- Checkout/order confirmation
- Responsive UI

## Run
1. Create `ecommerce_db` in MySQL using `database.sql`.
2. Open `src/main/resources/application.properties`.
3. Replace `YOUR_MYSQL_PASSWORD` with your MySQL root password.
4. Open the project in VS Code/STS/Eclipse.
5. Run `EcommerceApplication.java`.
6. Open http://localhost:8080

## Note
The checkout card fields are demonstration fields for an academic project. Do not use real card details.
